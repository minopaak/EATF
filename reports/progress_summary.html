01프로젝트 한눈에

목표

Time-MMD 위에 event annotation + cross-domain split + ROI 평가를 얹어, 기존 multimodal 방법이 cross-domain에서 무너지는지 정량 입증

핵심 가설

In-domain SOTA(VoT 등)의 case-based retrieval이 cross-domain에선 도움이 안 되거나 해롭다

  • 기여 — ① 이벤트 차원 추가 ② cross-domain LODO split ③ ROI 기반 평가 ④ memorization 검증
  • 구조 — 메인 연구(메커니즘 기반 예측) ↔ 본 데이터셋(그 motivation을 정량 입증)

07EDA 핵심 발견

  • 텍스트 sparsity 편차 큼 — report no-info 22.8% ~ 100%(Security), search 0% ~ 41.9% → cross-domain transfer 시 noise 요인
  • Security = search-only — report 모달리티 부재 (원본 빈 파일). "Report+Search 둘 다" 가정이 Security엔 불성립
  • 변수 구성 비대칭 — Agriculture/Economy만 다변량, 나머지 OT 단변량 → 공정 비교 위해 univariate 통일 옵션 고려
  • 공통 시기 — Security가 최단(1998-09~) → cross-domain 평가 기간 후보
